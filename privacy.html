プライバシーポリシー — lmtm-clips

最終更新：2026-10-18

lmtm-clips（以下「本ツール」）は、YouTube チャンネル「UltraLMTM切り抜きし隊(箱推し)」（@UltraLMTM_kirinuki）の運営者本人だけが、自分の PC で使うツールです。 同チャンネルに切り抜き動画を準備して投稿するために使います。本ツールを使う人は運営者 1 人だけで、ほかの人がサインインすることはありません。

Google のアカウントで許可していただく範囲

運営者の YouTube アカウントで、YouTube Data API の「youtube.force-ssl」の範囲を許可しています。これを使って行うのは次のことだけです。

  • 運営者が 1 本ずつ確認して承認した動画を、運営者のチャンネルに非公開でアップロードする（タイトル・説明・タグ・サムネイル・字幕を含む）
  • アップロードした動画に公開予約を設定する（予約の時刻の設定・変更）。予約の時刻になると、YouTube 側で公開されます
  • 運営者のチャンネルの再生リストに動画を追加する（再生リストが無ければ作る）
  • 運営者のチャンネルの動画の説明を書き換える（後から本編の URL を入れる時だけ）
  • 動画の状態（公開・非公開・処理中）と、元の配信が公開アーカイブになっているかを確かめる

あわせて YouTube Analytics API の「yt-analytics.readonly」（読むだけ）の範囲を許可しています。これを使って行うのは、運営者のチャンネルの動画の再生回数・視聴時間・平均視聴率などの数字を読み、どの切り抜きが見られているかを確かめることだけです。

動画の削除、他の人のチャンネル・アカウント・個人のデータへのアクセスはしません。

保存するデータ

動画 ID・タイトル・公開日時・投稿の記録・API の使用量を、運営者の PC の中のデータベースに保存します。OAuth のトークンは運営者の PC の中にだけ保存し、 ほかの場所には写しません。データベースなどの記録は、運営者自身のクラウドストレージ（Microsoft OneDrive）に毎日バックアップします（トークン・パスワードなどの秘密の情報は入れません）。

これらのデータを第三者に売ったり、共有したり、広告に使ったりはしません。運営者の PC のデータベースとバックアップを消せば、いつでも消去できます。

第三者のサービス

本ツールは YouTube API Services を使います。YouTube の利用規約（https://www.youtube.com/t/terms）と Google のプライバシーポリシー（https://policies.google.com/privacy）が適用されます。 許可は https://security.google.com/settings/security/permissions からいつでも取り消せます。

Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

Privacy Policy — lmtm-clips

Last updated: 2026-10-18

lmtm-clips ("the tool") is a desktop tool used only by the owner of the YouTube channel "UltraLMTM切り抜きし隊(箱推し)" (@UltraLMTM_kirinuki), on the owner's own computer, to prepare and publish clip videos to that channel. The owner is the only user; nobody else signs in to the tool.

Google user data and scopes

The owner authorizes the YouTube Data API scope "youtube.force-ssl" for the owner's own YouTube account. The tool uses it only to:

  • upload videos that the owner has reviewed and approved one by one to the owner's channel as private, with their title, description, tags, thumbnail and captions;
  • schedule the publication of those uploaded videos (set or change the scheduled time); YouTube makes each video public at that time;
  • add those videos to playlists on the owner's channel (creating a playlist if needed);
  • edit the description of the owner's own videos (only to add a link to the full video later);
  • check the status of videos (public, private, processing) and whether an original live stream has become a public archive.

The owner also authorizes the read-only YouTube Analytics API scope "yt-analytics.readonly". The tool uses it only to read the figures of the owner's own channel (views, watch time, average view percentage) to see which clips are watched.

The tool never deletes videos and never accesses other users' channels, accounts or personal data.

Data storage

Video IDs, titles, publish times, publishing records and API usage are stored in a database on the owner's computer. OAuth tokens are stored only on the owner's computer. The records (without tokens, passwords or other secrets) are backed up daily to the owner's own cloud storage (Microsoft OneDrive). The data is never sold, shared with third parties or used for advertising. It can be deleted at any time by deleting the local database and the backups.

Third-party services

The tool uses YouTube API Services. The YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy) apply. Access can be revoked at any time at https://security.google.com/settings/security/permissions.

Limited Use

lmtm-clips' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
